# LUBRIPRO DZ

## نظام إدارة وبيع الزيوت والشحوم الصناعية

برنامج مبيعات وإدارة مخزون مخصص لشركات توزيع الزيوت والشحوم الصناعية في الجزائر.

---

### الهدف من البرنامج
برنامج موجه خصيصاً لنشاط:
- بيع وتوزيع الزيوت والشحوم الصناعية
- التعامل مع المحاجر، المطاحن، شركات الأشغال العمومية، المصانع، والنقل
- البيع نقداً أو بالكريدي
- فواتير جزائرية كاملة (NIF / NIS / RC / AI)

---

### الوحدات الرئيسية

#### 1. القائمة الرئيسية
- المبيعات (Ventes)
- المشتريات (Achats)
- المخزون (Stock)
- العملاء (Clients)
- الموردين (Fournisseurs)
- الصندوق (Caisse)
- التقارير (Rapports)
- الإعدادات (Paramètres)
- النسخ الاحتياطي (Sauvegarde)

#### 2. إدارة العملاء
- ملف العميل (Code Client, Raison Sociale, Responsable, Adresse, Wilaya, Téléphone, Email, NIF, NIS, RC, AI, Solde, Limite Crédit)
- أنواع العملاء (Carrière, Minoterie, Entreprise, Garage, Usine, Transporteur, Agriculteur, Administration, Client Divers)
- كشف حساب العميل (Date, Document, Débit, Crédit, Solde)

#### 3. إدارة الموردين
- ملف المورد (Code Fournisseur, Nom, Adresse, Téléphone, NIF, NIS, RC, AI, RIB)

#### 4. إدارة المنتجات
- كود المنتج، المرجع، الباركود، التسمية، الماركة، العائلة، اللزوجة، التعبئة
- سعر الشراء، سعر البيع، المخزون الحالي، المخزون الأدنى
- الماركات: EXOL, PETROSAP, MAXWELL, PETRO BARAKA, RUBAX, MOBIL, SHELL, CASTROL...
- العائلات: Huile Moteur, Huile Hydraulique, Huile Transmission, Graisse EP0/EP1/EP2/EP3, Liquide Frein, Liquide Refroidissement, ATF, LDS, Additif...

#### 5. المبيعات والفواتير
- أنواع الوثائق: Facture, Bon de Livraison, Devis, Proforma, Avoir
- طرق الدفع: Espèces, Virement, Chèque, A Terme
- نظام الكريدي (Client, Facture, Montant, Versé, Reste, Date Échéance)
- طباعة الفاتورة بشكل جزائري كامل + المبلغ بالحروف

#### 6. المخزون
- دخول، خروج، مرتجع، جرد، تسوية
- تنبيهات: مخزون منخفض، منتج نافد، ديون مستحقة، عملاء مدينون

#### 7. التقارير
- مبيعات اليوم / الشهر
- المشتريات
- المخزون
- الديون (Créances / Dettes)
- الأرباح

#### 8. النسخ الاحتياطي
- تلقائي، يومي، يدوي
- نسخ سحابي (لاحقاً)

#### 9. صلاحيات المستخدمين
- Administrateur
- Comptable
- Vendeur
- Magasinier
- Commercial
